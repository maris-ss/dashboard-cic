## Sobre o Projeto
Construção de um dashboard funcional do zero em parceria com a empresa CIC. O objetivo foi resolver um problema de negócio real: transformar o processo maçante e "frio" de visualização e resolução de divergências de dados em um ambiente amigável, intuitivo e gamificado. 

## Principais Funcionalidades
- **Dashboard Customizável:** Usuários podem arrastar e organizar os *widgets* de acordo com a relevância para o seu acesso diário.
- **Gamificação de Divergências:** Dados apresentados em porcentagens, criando um senso de progresso que incentiva a resolução de pendências.
- **Dark Mode (Conforto Visual):** Implementação de um modo noturno na cor azul-marinho (evitando o preto puro) para maior conforto visual e estética autêntica.
- **Light Mode Otimizado:** Uso de tons quentes (fugindo do branco puro) para reduzir o cansaço ocular, além do uso de cores complementares nos gráficos para acelerar a interpretação dos dados.

## Tecnologias Utilizadas
- **Design:** Figma (UX/UI Design)
- **Front-End:** HTML, CSS, JavaScript
- **Data Visualization:** Chart.js
